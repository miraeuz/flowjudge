**5-mavzu. Nested If (Ichma-ich shart) – 1-qism**

*Asosan 2 darajali nested If. Hayotiy vaziyatlar bilan.*

1. Foydalanuvchi yoshini kiritsin. Agar yoshi 18 dan katta yoki teng bo‘lsa: Agar yoshi 60 dan katta bo‘lsa → «Pensiyaga chiqqan», aks holda → «Ishlash yoshida». Aks holda → «Voyaga yetmagan».

2. Foydalanuvchi bahosini kiritsin (1–5). Agar baho 4 yoki 5 bo‘lsa: Agar baho 5 bo‘lsa → «A’lo», aks holda → «Yaxshi». Aks holda → «Yaxshiroq o‘qish kerak».

3. Foydalanuvchi pul miqdorini kiritsin. Agar pul 50000 dan ko‘p bo‘lsa: Agar pul 100000 dan ko‘p bo‘lsa → «Yetarli pul bor», aks holda → «O‘rtacha pul». Aks holda → «Pul yetarli emas».

4. Foydalanuvchi haroratni kiritsin. Agar harorat 0 dan katta bo‘lsa: Agar harorat 25 dan katta bo‘lsa → «Issiq», aks holda → «Iliq». Aks holda → «Sovuq».

5. Foydalanuvchi yoshini va bahosini kiritsin. Agar yoshi 16 dan katta bo‘lsa: Agar bahosi 5 bo‘lsa → «Barakalla!», aks holda → «Yaxshi, davom eting». Aks holda → «Hali yoshsiz».

6. Foydalanuvchi ismini va yoshini kiritsin. Agar ism «Ali» bo‘lsa: Agar yoshi 18 dan katta bo‘lsa → «Salom katta Ali», aks holda → «Salom yosh Ali». Aks holda → «Salom».

7. Foydalanuvchi ballini kiritsin (0–100). Agar ball 60 dan yuqori yoki teng bo‘lsa: Agar ball 85 dan yuqori bo‘lsa → «A’lo», aks holda → «Yaxshi». Aks holda → «O‘tmadi».

8. Foydalanuvchi nechta xato qilganini kiritsin. Agar xato 0 bo‘lsa → «Ajoyib!». Aks holda: Agar xato 3 dan kam bo‘lsa → «Yaxshi», aks holda → «Ko‘p xato qilibsiz».

9. Foydalanuvchi kun raqamini kiritsin (1–7). Agar kun 6 yoki 7 bo‘lsa → «Dam olish kuni». Aks holda: Agar kun 1 bo‘lsa → «Dushanba – og‘ir kun», aks holda → «Oddiy ish kuni».

10. Foydalanuvchi yoshini kiritsin. Agar yoshi 7 dan katta bo‘lsa: Agar yoshi 17 dan kichik bo‘lsa → «Maktab o‘quvchisi», aks holda → «Maktabni tugatgan». Aks holda → «Maktab yoshiga yetmagan».

11. Foydalanuvchi pulini va mahsulot narxini kiritsin. Agar puli narxdan ko‘p yoki teng bo‘lsa: Agar puli narxdan 2 marta ko‘p bo‘lsa → «Oson xarid qilasiz», aks holda → «Xarid qilishingiz mumkin». Aks holda → «Pulingiz yetmaydi».

12. Foydalanuvchi bahosini kiritsin. Agar baho 5 bo‘lsa → «A’lo». Aks holda: Agar baho 4 bo‘lsa → «Yaxshi», aks holda → «Qoniqarli yoki yomon».

13. Foydalanuvchi nechta kitob o‘qiganini kiritsin. Agar 5 dan ko‘p bo‘lsa: Agar 15 dan ko‘p bo‘lsa → «Juda ko‘p o‘qibsiz», aks holda → «Yaxshi o‘qiyapsiz». Aks holda → «Ko‘proq o‘qing».

14. Foydalanuvchi yoshini va jinsini kiritsin (o‘g‘il/qiz). Agar yoshi 18 dan katta bo‘lsa: Agar jinsi «o‘g‘il» bo‘lsa → «Katta yigit», aks holda → «Katta qiz». Aks holda → «Hali yosh».
