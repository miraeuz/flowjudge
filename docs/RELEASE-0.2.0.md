## Flowgorithm Academy 0.2.0

Download **Flowgorithm-Academy-Setup-0.2.0.exe** — the only student installer (Windows x64).

### What changed
- Mirae violet learning workspace, day/night/system modes, flexible layouts, Uzbek-first UI and English option.
- Learning path, 15 lessons and 750 practice exercises: 20 classwork + 30 homework per topic. Content includes generated scenario/parameter variants; it is not 750 unique algorithms.
- Search, homework tabs, hints, progress, first-solve XP, attempt history, backup/merge and CSV export.
- Worker-isolated `.fprg` judging with time/memory limits, structural requirements, malformed-file checks and hidden-error redaction.
- Existing Input exercise IDs and existing local progress are preserved.
- One-click installer, Desktop/Start Menu shortcuts. No Mac, Linux or portable builds.

### Before teaching
Flowgorithm must be installed separately to author files. Uzbek wording and the new practice families need teacher review. This release does not add auto-update, certificates, proctoring or complete Flowgorithm semantic parity.

Telegram activation retains the previous dedicated-bot configuration. The credential is embedded and extractable; a server-side relay is still needed for broader distribution. The setup is unsigned. Real Telegram delivery and installation should be smoke-tested on a classroom Windows PC.
